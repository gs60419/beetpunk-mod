模組核心

不是增加一種材料，
而是建立一條甜菜文明。

為極限空島與低資源生存設計。玩家從原版甜菜出發，讓每次收成同時打開新的材料分支；最終透過經書與神殿，把手工勞動逐步轉化為範圍能力與自動化。
